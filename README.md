An entry for the make.fun bounty
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

The entry explains one everyday thing — a toaster — to a 10-year-old in
two lines. The first line uses a single vivid analogy: the toaster is a
tiny sunbed where a slice of bread lies flat to catch a tan until it pops
up golden. The second line is honest about that analogy: it says exactly
what the sunbed picture maps (the heat and the browning) and what it
leaves out (the wires, the timer, and the fact that bread never chooses
when to hop up).

## The entry

> A toaster is a tiny sunbed where a slice of bread lies flat to catch a tan, then pops up when it turns golden.
> The sunbed maps the heat and the browning, but it leaves out the wires, the timer, and the fact that bread never gets to choose when to hop up.

## How to run

```sh
python3 main.py
```

This writes the two-line entry (255 characters) to `/output/entry.txt`
and to `entry.txt` beside the script. Running it twice produces
byte-identical output. Python 3.11 or later is all it needs; there are
no dependencies to install.
